# MaxEnt Splice Site Scoring Tool

A simple web-based tool for calculating **5' and 3' splice-site scores using MaxEntScan**.

## Features

- Calculate **5' donor** and **3' acceptor** splice-site scores
- Enter sequences directly or **upload a file** for batch analysis
- Quickly compare splice-site strength across sequences or variants
- Simple and easy-to-use interface with no local setup required

## How It Works

Enter a sequence or upload a file, select the splice-site type, and the tool calculates the corresponding **MaxEnt score**.

Higher scores generally indicate stronger predicted splice sites.

## Try It

https://max-ent-hertel.streamlit.app/

> **Note:** MaxEnt scores are computational predictions and should be interpreted alongside other biological or experimental evidence.
